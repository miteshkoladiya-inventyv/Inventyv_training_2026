# Angular Product Cart – v16 (NgModule + Services)

## 📌 Overview
This project implements a **Product List and Cart** using **Angular v16** following
the **classic NgModule-based architecture**.

The application demonstrates:
- Component-based UI
- Shared state via services
- Traditional Angular module setup

---

## 🧠 Key Concepts Used
- NgModules (`app.module.ts`)
- Component declarations
- Service-based state management
- Angular change detection
- Feature separation

---

## 🏗️ Architecture
- **ProductListComponent** – Displays products
- **CartComponent** – Displays cart and controls quantity
- **CartService** – Manages shared cart state
- **AppModule** – Registers all components

---


## 🔄 State Management
- Cart state stored in a service
- Components access state via getter methods
- Updates handled through service methods

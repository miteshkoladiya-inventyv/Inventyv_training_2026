# User Profile Card Workspace

This workspace contains three Angular versions of the same **user-profile-card** project:

- [angular-v16/user-profile-card](angular-v16/user-profile-card)
- [angular-v18/user-profile-card](angular-v18/user-profile-card)
- [angular-v21/user-profile-card](angular-v21/user-profile-card)

## Quick Start (any version)

From inside one of the versioned folders, run:

```bash
npm install
npm start
```
